# Society Archive

This repository is the public catalogue and archive for materials the Economics Society has permission to share. The Society’s shared economic data lives in [Database-](https://github.com/Pondi-Uni-Economics-Society/Database-); this archive is for Society outputs and records.

## What belongs here

- Approved presentation slides, handouts, and event summaries
- Final student magazine issues and approved working papers
- Bibliographic records for talks and publications
- Links to Society event recordings hosted on an approved media platform

## Before contributing

Contribute through a pull request. Confirm author permission, co-author agreement, attribution, reuse rights for images and other materials, and any relevant department approval. Label the review status accurately. Student editing is not the same as formal academic peer review.

This repository is public. Never add personal, confidential, restricted, respondent-level, or otherwise uncleared material. The repository `.gitignore` blocks common raw-survey folders and spreadsheet workbooks to reduce accidental uploads; it is not a security boundary, does not remove files already tracked, and can be bypassed. Review every file before committing, and never force-add raw or identifiable data. Put only approved, shareable aggregate datasets in the Database repository, preferably as documented CSV. Do not upload large video files here; add an approved recording link and its descriptive record instead. See the Society’s [deposit guidance](https://github.com/Pondi-Uni-Economics-Society/Database-/blob/main/governance/SUBMITTING_DATA.md) for related data and permission principles. Repository-level archive procedures still need Society and Department confirmation.
