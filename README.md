# Society Archive

This repository is the public catalogue and archive for materials the Economics Society has permission to share. The Society’s shared economic data lives in [Database-](https://github.com/Pondi-Uni-Economics-Society/Database-); this archive is for Society outputs and records.

## What belongs here

- Approved presentation slides, handouts, and event summaries
- Final student magazine issues and approved working papers
- Bibliographic records for talks and publications
- Links to Society event recordings hosted on an approved media platform

## Before contributing

Contribute through a pull request. Confirm author permission, co-author agreement, attribution, reuse rights for images and other materials, and any relevant department approval. Label the review status accurately. Student editing is not the same as formal academic peer review.

This repository is public. Do not add personal, confidential, restricted, or otherwise uncleared material. Do not upload large video files here; add an approved recording link and its descriptive record instead. See the Society’s [deposit guidance](https://github.com/Pondi-Uni-Economics-Society/Database-/blob/main/governance/SUBMITTING_DATA.md) for related data and permission principles. Repository-level archive procedures still need Society and Department confirmation.
