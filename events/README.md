# Events and presentations

Create one folder per approved event using the date and a short event ID, for example `2026-11-15-idec-labour-markets`.

Include a brief event record with the date, title, format, speakers or presenters as they have agreed to be named, abstract or summary, and links to permitted slides or handouts. Obtain permission before posting photographs, recordings, or presentation materials. Do not include attendee lists or private contact details.
